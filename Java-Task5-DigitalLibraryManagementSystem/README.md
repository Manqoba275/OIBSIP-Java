# Digital Library Management System

OASIS INFOBYTE - Java Development, Task 5.

**Status: scaffold only. Implementation has not started.**

## Required technology

Java (Servlets/JSP or Spring Boot), MySQL or SQLite, HTML/CSS.

## Requirements checklist

- [ ] Admin login with access to all system features.
- [ ] Admin: add books with title, author, ISBN, category and quantity.
- [ ] Admin: edit and delete books.
- [ ] Admin: view issued books and due dates.
- [ ] Admin: view and manage registered members.
- [ ] Admin: mark fines as paid.
- [ ] User registration and login.
- [ ] Browse books by category and search by title or author.
- [ ] Issue books, decrement available quantity and record the due date.
- [ ] Return books and increment available quantity.
- [ ] Calculate overdue fines automatically (document example: 5 rupees per day).
- [ ] Reserve books currently issued to another user.
- [ ] Store contact/query messages in the database and show them to admins.

## Develop in VS Code

This is a web application. Choose Servlets/JSP or Spring Boot, then add your own build file, framework dependencies, database driver and application entry point. No framework or server has been selected for you. The directories are placeholders; no runnable web app has been implemented.
